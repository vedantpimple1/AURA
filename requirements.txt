5. REDIS EXPLANATION: IS IT IMPLEMENTED & DO YOU NEED IT?
--------------------------------------------------------------------------------
1. Redis implementation
   YES. Full BullMQ + ioredis queue architecture is implemented in:
   - src/services/queue/queue.config.ts
   - src/services/queue/notification.worker.ts
   - src/services/queue/notification.queue.ts

AURA has an automatic dual-mode fallback:
   - When QUEUE_ENABLED="false" (default), the delivery worker automatically
     uses DATABASE POLLING MODE.
   - It polls PostgreSQL every 10 seconds for pending notification emails and
     dispatches them asynchronously with ZERO Redis setup and ZERO cost.

3. From where do you get REDIS_URL if you ever want Redis (for 500+ scale)?
   - On Render: Click "New +" -> "Redis" (Render generates an internal/external Redis URL).
   - On Upstash: Free cloud Redis at https://upstash.com (Copy Redis URL).
   - On AWS: AWS ElastiCache for Redis endpoint.
   - On Azure: Azure Cache for Redis primary connection string.


6. COMPLETE DATABASE & PRISMA SETUP ON AZURE / AWS / LINUX
--------------------------------------------------------------------------------
The commands below set up the entire database from scratch on AWS RDS, Azure
PostgreSQL, or an Ubuntu Linux VM:

Step 1: Create Database & User (in PostgreSQL / Cloud Console):
  CREATE USER aura_user WITH PASSWORD 'YourStrongPassword123!';
  CREATE DATABASE aura_db OWNER aura_user;
  GRANT ALL PRIVILEGES ON DATABASE aura_db TO aura_user;

Step 2: Set the Connection String in backend/.env:
  AWS RDS:
    DATABASE_URL="postgresql://aura_user:YourStrongPassword123!@<rds-endpoint>.amazonaws.com:5432/aura_db?sslmode=require"
  Azure PostgreSQL:
    DATABASE_URL="postgresql://aura_user:YourStrongPassword123!@<server-name>.postgres.database.azure.com:5432/aura_db?sslmode=require"
  Render / Neon:
    DATABASE_URL="postgresql://aura_user:YourStrongPassword123!@<host>:5432/aura_db?sslmode=require"

Step 3: Run Prisma Migrations & Seed (cd backend):
  1. Generate Prisma Client:
     npx prisma generate

  2. Apply All SQL Migrations (creates 23 tables, foreign keys & indexes):
     npx prisma migrate deploy

  3. Seed Production Roles, Superadmin, Admin, Member & Store Catalog:
     npm run db:seed
     (Creates SUPERADMIN, ADMIN, USER, RECOVERY_OPERATOR roles & default items)

  4. (Optional) Open Web Database Browser:
     npx prisma studio
